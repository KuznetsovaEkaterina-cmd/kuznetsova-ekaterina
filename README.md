## О себе и мотивация

В тестирование я пришла осознанно, из инженерной и управленческой сферы:

- **Образование:** РГУ им. А. Н. Косыгина, инженер по специальности «Автоматизированные системы обработки информации и управления» (2002).
- **Опыт до QA:** менеджер федеральной сети оптик «Счастливый взгляд». Работа с документацией, учётом и клиентскими обращениями воспитала внимательность к деталям и привычку смотреть на продукт глазами пользователя.
- **Переподготовка:** курс «Инженер по тестированию» в Яндекс Практикуме , диплом с полным циклом тестирования сервиса.

**Почему QA.** Инженерное образование приучило меня работать с данными и проверять гипотезы по шагам, а управленческий опыт — отвечать за результат. В тестировании это соединилось: мне нравится декомпозировать требования в проверки и находить до того, как с ними столкнётся пользователь.

## Навыки и инструменты


**Виды тестирования:**
- функциональное, регрессионное, UI-тестирование;
- валидация форм и негативные сценарии;
- тестирование REST API;
- тестирование мобильных приложений ;
- проверка данных в БД и серверных логах.

**Тест-дизайн и документация:**
- классы эквивалентности, граничные значения;
- чек-листы, тест-кейсы, баг-репорты;
- работа с требованиями и API-документацией.

**Инструменты:**
- **Postman** — запросы к REST API, статус-коды, JSON, переменные окружения;
- **SQL / PostgreSQL** — SELECT, JOIN, GROUP BY, HAVING, CASE WHEN; консоль psql;
- **DevTools браузера** — Network, Console, Elements;
- **Android Studio** — эмулятор для мобильного тестирования;
- **SSH** — анализ логов (tail, grep);
- **Excel / Google Sheets** — оформление тестовой документации.
